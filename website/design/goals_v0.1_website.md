GOAL #1

The Hero Section should feel:

- Calm
- Premium
- Beautiful
- Warm
- Intentional
- Professional
- Effortless
- Quietly Powerful
- Welcoming


-----------------------------


GOAL #2

Users should immediately feel:

- This was built for me.
- Local AI doesn't need to be difficult.
- I want to learn more.
- This feels beautiful.
- This feels effortless.


-----------------------------


GOAL #3

The Hero Section consists ONLY of:

- Background
- Temporary Logo Placement
- Mission Statement
- Supporting Text
- Scroll Indicator
- Subtle Animations
- Responsiveness


-----------------------------


GOAL #4

The Hero Section should NEVER feel:

- Flashy
- Information Dense
- Gimmicky
- Restrictive
- Overwhelming
- AI Generated Looking
- Loud
- Distracting


-----------------------------


GOAL #5

Animations should feel:

- Smooth
- Intentional
- Subtle
- Calm
- Premium

NOT:

- Fast
- Distracting
- Over the top
- Flashy


-----------------------------


GOAL #6

The User should ALWAYS remain
the hero.

Meaning:

The Hero Section should NOT say:

"LOOK WHAT VANGUARD CAN DO!"

It SHOULD say:

"LOOK WHAT VANGUARD WAS BUILT
TO DO FOR YOU."


-----------------------------


GOAL #7

The Hero Section should answer
ONLY ONE QUESTION:

"What should users feel after
15 seconds?"

Answer:

- Welcomed
- Understood
- Curious
- Interested in continuing
their journey through the
website.


-----------------------------


GOAL #8

LESS IS MORE.

Whitespace is preferred over
information overload.

Beautiful subtle movement is
preferred over flashy animations.

Intentional design is preferred
over feature packed design.


-----------------------------


GOAL #9

If something looks bad or goes
against Vanguard's philosophy
we WILL change it.

Nothing is final until we see it
alive.

Version 0.000001 exists ONLY for
learning purposes.


-----------------------------


GOAL #10

DO NOT BUILD:

- Navigation Bars
- Github Buttons
- Contact Pages
- Documentation Pages
- Future Website Sections
- Demo Pages
- Anything Else

ONLY the Hero Section exists
today.
